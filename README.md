# HTML-Projekt – Weltraumausflüge

Projektseite für Weltraumausflüge, umgesetzt mit HTML5, CSS3, Bootstrap und JavaScript.

## Überblick

Statische Website mit Startseite sowie Impressum und Datenschutzerklärung.

## Tech-Stack

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Projektstruktur

```text
├── index.html        # Startseite
├── impressum.html
├── datenschutz.html
├── css/              # Styles
├── js/               # Skripte
└── images/           # Bilder
```

## Nutzung

Repository klonen und `index.html` im Browser öffnen:

```bash
git clone https://github.com/Busaschie/HTML-Projekt.git
cd HTML-Projekt
```

Alternativ mit lokalem Server:

```bash
python -m http.server 8000
```

Aufruf unter `http://localhost:8000`.
